# Contributing

Use Node 24.x and Rust 1.99.1. Preserve the lockfiles and documented capture/config contracts. Run frontend checks, browser checks, core Rust tests and formatting; Windows-specific changes also need a native Windows build.

Changes affecting writes or recovery need tests for interrupted operations, external edits and unsupported schema. Metric changes need numerical fixtures and an explanation of run-level uncertainty. Never substitute frame-level sample counts for independent experiment runs.

Use existing Radix primitives for controls/dialogs and update both languages. Keep the synthetic browser adapter separate from native behavior. Label screenshots and reports as synthetic, imported or live. No fabricated FPS claims, human replay uploads, private bot code or credentials.

Model/device compatibility is evidence, not a checklist tick: identify actual tested hardware and versions. Do not expand the write-version allowlist using an unverified forum tweak. Contributions are MIT; retain upstream notices. Be respectful, criticize the work rather than the person, and follow SECURITY.md for sensitive reports.
